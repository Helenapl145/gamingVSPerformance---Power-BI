# 🎮 Gaming Hours vs Performance - Power BI

## 📌 Sobre o Projeto

Este projeto consiste na construção de um painel desenvolvido no **Power BI**, utilizando dados relacionados ao tempo de jogos e sua relação com aspectos como **foco, estresse, produtividade e performance**.

O dashboard foi desenvolvido a partir do dataset **Gaming Hours vs Academic and Work Performance**, disponível no Kaggle.

---

## 📊 Indicadores Principais

* Horas Jogadas
* Média de Estresse
* Média de Foco
* Produtividade
* Horas Dormidas x Horas Jogadas
* Foco por Tipo de Jogo
* Impacto na Performance
* Horas Jogadas x Produtividade
